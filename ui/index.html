VidLibOrganizer

Find duplicate video files across local folders and external drives, then review the evidence at your own pace. Your collection stays where it belongs: with you.

Exact file size
Groups files with identical byte lengths. Different videos can share a size, so these matches are candidates.
Full-content MD5
Compares MD5 hashes of complete files in matching size groups. Designed to find accidental duplicates, not to authenticate untrusted files.
Local by design
No accounts, uploads, metadata services, or background network requests. Saved folder paths stay on this computer.
You choose what happens
Scanning never changes files. Keep all copies, move selected files to another folder, or explicitly confirm permanent deletion. At least one file in each group must remain.
Interpreting space
Redundant bytes assume keeping one file per group. This is a logical estimate; hard links may already share disk space. Review size-only candidates before making any changes.
